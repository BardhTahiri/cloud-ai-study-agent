# Demo Plan

Minimum demo path:

```text
1. Create or select a course.
2. Upload one academic PDF.
3. Start AI processing.
4. Show task status.
5. Display generated summary.
6. Display generated quiz.
7. Display generated study plan.
```

Current MVP shortcut:

```text
1. Start backend.
2. Start frontend.
3. Use the sample material already shown in the dashboard.
4. Click Generate study package.
5. Show the task appearing as pending/running.
6. Wait for the dashboard to poll and display generated topics, summary, quiz, and plan.
```

Optional advanced demo:

```text
1. Student answers quiz.
2. System detects weak topics.
3. AI updates the study plan based on weak topics.
```
