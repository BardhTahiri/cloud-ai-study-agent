# Demo Plan

Minimum demo path:

```text
1. Create or select a course.
2. Upload one academic PDF.
3. Start AI processing.
4. Show task status.
5. Display generated summary.
6. Display generated quiz.
7. Display generated study plan.
```

Optional advanced demo:

```text
1. Student answers quiz.
2. System detects weak topics.
3. AI updates the study plan based on weak topics.
```
